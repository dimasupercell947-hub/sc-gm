# APEX — Night Drive

A polished, dependency-free browser driving experience. It uses a custom canvas renderer to create a responsive pseudo-3D coastal highway, moving traffic, road-side lighting, a cockpit view, and live vehicle telemetry.

## Run it

Open `index.html` in any modern browser, or serve the directory:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Controls

- **W / Up** — accelerate
- **S / Down** — brake
- **A / D** or **arrow keys** — steer
- **Space** — handbrake
- **Esc** or **Pause** — pause the simulation
